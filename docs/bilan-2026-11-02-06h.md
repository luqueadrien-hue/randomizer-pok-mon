# Bilan du 2 novembre 2026 — Marché, Randomizer et Centre Pokémon

## État vérifié dans le dépôt

- **609 occurrences historiques** = 250 entrées du tableau `TRAINER_MARKET_SEED` dans `index.html` + 359 entrées de `data/trainer-market-expansion.js`.
- **362 identités espèce + forme** différentes dans le catalogue brut, dont **12 entrées de formes alternatives** présentes dans l'index français extrait. Ce n'est pas 604 espèces uniques.
- Répartition par rang : **39 / 41 / 205 / 52 / 26 / 51 / 117 / 78**, soit huit rangs représentés.
- Provenances de **générations I à IX**, mais catalogue historique **non exhaustif**. Cinq occurrences attestées ont été ajoutées au-delà des 604 initiales : Ferdeter et trois variantes de starter de Menzi, ainsi que Limaspeed de Goyah. La fiche de Menzi a aussi été corrigée (Deusolourdo à trois segments et Lougaroc diurne à la place de l'attribution erronée de Famignol).

## Développement réellement enregistré

1. `portail.html` : nouvelle page d'accueil en français avec six rubriques (Randomizer, Stratégie, Pokédex, Guides, Reproduction, Outils), mise en page responsive, navigation et avertissements de couverture.
2. `data/encyclopedie-index.js` : index français partiel des 362 espèces/formes déjà attestées dans le Marché. L'index n'est pas un Pokédex français national complet.
3. `data/portail.js` : recherche et grilles visuelles des Pokémon, objets, talents et capacités ; filtres génération et type pour les Pokémon ; catégories d'objets ; fiches Pokémon avec statistiques, talents, reproduction, chaîne d'évolution, capacités par groupe de versions ; fiches d'objets/talents/capacités. Les sprites PokéAPI sont chargés progressivement, y compris les formes alternatives connues, avec repli si indisponibles.
4. `index.html` : menu d'accueil intégré à la racine, liens vers le portail et prise en charge des liens `?outil=randomizer|strategy|damage|types|nature|abilities|moves|rules|training|mechanics`. Les jeux et salons existants ont été conservés.
5. Marché : réinitialisation renforcée pour rejeter une modification concurrente de `updated`, du jeu ou du budget même sans nouvel achat.
6. Tests : `tests/portail.test.mjs`, `tests/portail-dom.test.mjs`, nouveau test de réinitialisation dans `tests/trainer-market.test.mjs` ; workflow GitHub Actions élargi.

## Audit structurel des autres jeux

Le sélecteur de modes dans `index.html` contient **71 options** : **57 modes numérotés** et **14 modes non numérotés**, dont **1 explicitement désactivé** (« Draft des 6 Dresseurs — en préparation »). C'est un inventaire statique du menu, **pas une preuve que les 70 autres options sont fonctionnelles en réseau**. Les tests de salons, de synchronisation et de compatibilité par mode restent à mener. Les nouveaux liens profonds ne modifient pas les rôles ou les états des parties.

## Limites et risques importants

- **Sécurité Firebase** : les dernières règles connues (`".read": "auth != null"`, `".write": "auth != null"` à la racine) restent trop permissives. Les achats client ne résistent pas à des écritures directes malveillantes. Aucune Cloud Function sécurisée ni règle de production restrictive n'a été déployée. Ne pas présenter le marché comme sécurisé.
- **Disponibilité Switch, DLC et HOME** : les listes de Pokédex et les transferts sont encore partiels ; le filtre de jeu du portail sélectionne les capacités par groupe de versions, pas la compatibilité certifiée de l'espèce. L'encyclopédie doit être enrichie d'une base de compatibilité exhaustive et vérifiée.
- **Traductions** : l'index français couvre les espèces/formes attestées du Marché, pas les 1 025 Pokémon. Les autres espèces peuvent apparaître sous leur nom API anglais jusqu'à l'ouverture de la fiche ; les objets ont un dictionnaire français partiel ; les talents et capacités reçoivent leur nom français à l'ouverture lorsque PokéAPI le fournit.
- **Formes** : douze formes alternatives dans l'index local, pas toutes les formes existantes. Les sprites sont demandés à PokéAPI et peuvent manquer.
- **Movepool** : la fiche affiche les 24 premières capacités référencées pour la version choisie, pas le movepool complet. Les données PokéAPI peuvent être incomplètes pour les jeux récents.
- **Autres jeux** : audit structurel limité ; aucun nouveau mode n'a été activé ni aucune règle utilisateur modifiée.
- **Hébergement** : l'ajout au dépôt ne prouve pas que GitHub Pages a publié les nouvelles pages.

## Priorités suivantes

1. Migrer les achats vers des fonctions serveur autoritaires et des règles Firebase réellement restrictives, puis tester en émulateur et à deux comptes.
2. Tester le déploiement GitHub Pages et la navigation du portail dans de vrais navigateurs PC/mobile.
3. Compléter l'index français et les variantes avec une source locale vérifiée ; contrôler les traductions et sprites.
4. Construire une matrice de compatibilité Switch/DLC/HOME par espèce et forme, sans déductions trompeuses à partir des seuls movepools.
5. Compléter les équipes historiques, surtout dresseurs ordinaires et sbires, avec références et combats distincts.
6. Étendre les tests de navigation et les tests réseau, puis auditer les autres modes un par un.
