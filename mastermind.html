🧠 Mastermind Pokémon

Deux joueurs, six manches par joueur, quatre Pokémon distincts par code et quatre essais maximum. Le décodeur choisit un Pokémon du code s'il gagne ; sinon le codeur lui impose un Pokémon du code.

Version locale sur le même écran : passez l'appareil entre les joueurs. Le codeur prépare le code à l'abri du regard de l'autre joueur. Le mode réseau Firebase n'est pas encore intégré.
