# Randomizer Pokémon

Projet du Randomizer Pokémon multi-jeux et futur mode multijoueur.

## Version de base
La version web actuelle est basée sur la V30 :
- défis Pokémon multiples ;
- filtres génération / jeu et légendaires ;
- équipes joueurs ;
- mode Box PC aléatoire 30 emplacements ;
- modes indices, Pokédex, talents, évolutions, enchères, etc.

## Multijoueur
La prochaine étape est la V31 : salons avec code, hôte/joueurs et synchronisation des choix/Box PC.

Le fichier `index.html` contient l'application web actuelle.
